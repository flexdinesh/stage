# Projects

A Stage project organizes workspace rows, tasks, trees, schedules and
snippets under one title. Stage owns the project's ID, title and archive
state. Each [connection](/docs/concepts/connections) owns its workspace catalog.

## Find or create a project

In **Projects**, open the group for your repository or folder. Stage groups
new workspaces when strong evidence identifies one existing project. A
matching repository origin and a known checkout subpath can group clones
across machines. Local directory and checkout evidence is scoped to the
machine that holds the files. Ambiguous workspaces get their own groups.

Use **New project** and enter a title to create an empty group for planning.
To add a workspace to it, open the existing group that lists the workspace,
choose **Move to project**, select the target, then review and confirm.
When a group has several members, use **Separate** from a workspace row
to place it in a new group. If someone
changes the membership while the preview is open, review the updated
preview before confirming.

## Choose where work runs

When saving a task that will run or creating a schedule, select a connection
and an exact workspace on it. A launch uses the selected pair even if
someone later moves the workspace to a different group. Save an untimed
backlog task for planning if you need to choose the workspace later.

A missing workspace or retired connection can still appear in project
history. Select a replacement explicitly to run future work there. Old
links, snippets and recorded work remain available in **Project history**.

## Archive

Archive and unarchive projects in the **Project actions** menu. A harness archive is stored as
workspace information. External removal preserves Stage tasks and history.

## Project scope

The sidebar lists projects with open work by recent activity, with counts for needs input, waiting on you and running. Pick one to scope Dashboard, Tasks, Trees and Schedules to it. Each device remembers the choice. Details: [App reference](/docs/reference/app).
