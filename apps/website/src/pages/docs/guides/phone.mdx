# Answer from your phone

Agents stop to ask questions. This guide gets those needs-input notifications onto an iPhone or iPad and lets you answer from it. It uses Tailscale serve, which gives Stage a trusted HTTPS address on your tailnet with nothing to install on the phone beyond Tailscale.

You need Stage running as a service ([Desktop app](/docs/usage/desktop) or [Self-hosted server](/docs/usage/server)), Tailscale on the Stage machine and the phone, and HTTPS certificates enabled for your tailnet.

:::steps

### Add a TCP listener

In `service.env` (`~/.config/stage/service.env` on Linux, `~/Library/Application Support/stage/service.env` on macOS), set:

```sh
STAGE_LISTEN=unix,127.0.0.1:7380
```

### Serve it over HTTPS

On the Stage machine:

```sh
tailscale serve --bg http://127.0.0.1:7380
```

Stage is now at `https://<machine>.<tailnet>.ts.net`, reachable only from your tailnet.

### Trust that address

Add the origin to `service.env`, then restart:

```sh
STAGE_ALLOWED_ORIGINS=https://<machine>.<tailnet>.ts.net
```

```sh
stage service restart
```

For shared access, set `STAGE_PUBLIC_URL` to this HTTPS origin. A personal server can use either setting.

### Install the app

On iOS or iPadOS 16.4 or later, open the address in Safari and tap Share > **Add to Home Screen**. Then open Stage from the Home Screen: notifications work only in the installed app.

### Enable notifications

In the installed app, sign in if the server uses shared access. Open Settings > Notifications. Under **This device**, tap **Enable notifications**, then **Send test**.

### Pick which events notify

In the same page, choose the events. The choice applies to all of your signed-in devices in shared access.

### Answer

When a notification arrives, tap it to open the task (or the inbox, for a session started outside Stage). A task that needs input offers **Open in T3** (or **Open in OpenCode**): answer in the harness session. The phone must reach the harness's web address too; set it in the connection's settings ([Connections reference](/docs/reference/connections)).

:::

:::warning
Anyone who reaches a personal Stage listener through the tailnet can read tasks and launch agents. Use [shared access](/docs/usage/server#enable-shared-access) when trusted people need their own sign-in and inbox.
:::

With a real domain or a LAN name instead of Tailscale, use Caddy or another reverse proxy ([HTTPS and push notifications](/docs/usage/server#https-and-push-notifications)).
